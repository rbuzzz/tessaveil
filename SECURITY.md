# Security policy

Security audit: not yet independently completed

This repository is research, not a production vault. There is no supported release or safe real-funds use at this stage.

Please report a suspected vulnerability privately through the repository's GitHub **Security → Report a vulnerability** flow (GitHub private vulnerability reporting) when available. If that flow is unavailable, contact the repository owner through GitHub to arrange a private channel before sharing technical details. Do not open a public issue containing an exploit, real recovery phrase, private key, token, or vault.

Include affected commit or version, a synthetic reproducer, expected and observed behavior, and security impact. Do not test against another person's data. The maintainers will acknowledge and coordinate disclosure as capacity permits; no response-time guarantee is made.

Public source, CI, and internal review are not an independent security audit. The threat model and release security gates are still planned.
