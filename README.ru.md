# Tessaveil

Tessaveil — офлайн-приложение Windows для создания зашифрованных таблиц с
ложными словами для уже существующей мнемонической резервной копии. В этой
ветке находится работающий **неподписанный кандидат Windows v1 только для
синтетических данных**. Это не RC, не стабильный релиз и не разрешение работать
с реальными секретами или средствами. Текущий вердикт:
**NO-GO для реальных данных**.

Security audit: not yet independently completed

Приложение создаёт, открывает и сохраняет хранилище schema 2 с расширением
`.tessaveil-alpha`, управляет несколькими защищёнными листами, использует
неизменяемые снимки пользовательских словарей, выполняет нейтральный Spin одной
строки, хранит пользовательскую отметку «Проверено мной», создаёт побайтно
идентичную аутентифицированную резервную копию, восстанавливает её в новый файл
и меняет мастер-пароль. Поддерживаются русский/английский, системная/светлая/
тёмная тема, клавиатура, защитная завеса, явная блокировка и проверенные на
рабочем компьютере масштабы. Tessaveil никогда не принимает и не возвращает
целую фразу или ключ порядка и не выводит ключи, адреса или балансы кошелька.

Выбираются только три точных профиля, каждый на 24 строки:

- `mytonwallet-native / ton-native-generated`, web,
  `26.9.8-source-f042bcc06b84f0cec928a29795f1cb8bf60a3e9c`;
- `tonhub / ton-native-generated`, Android,
  `2.5.45-source-a2503f79d14868d65349ad7035d18389c6e2f996`;
- `tonkeeper-classic / ton-native-generated`, web,
  `source-4942adcdcddf55d57e3d3fc3676f019caf87357e`.

Tonkeeper Multichain, Gram Wallet, мультичейн-режим MyTonWallet и остальные
обязательные записи каталога видимы, но недоступны при их фактическом конечном
статусе. Для недоступного режима используйте процедуру резервирования и
восстановления исходного доверенного кошелька. Импорт или общий словарь не
доказывают совместимость генерации. См. [каталог](docs/catalog.ru.md) и
[двуязычную инструкцию кандидата](docs/alpha/user-guide.md).

Никогда не передавайте фразу восстановления, ключ порядка, приватный ключ,
резервную копию кошелька со средствами или пользовательский vault в issues,
pull request, тесты, CI, агентам или на сайты. Tessaveil кратковременно видит
текущее слово и столбец, не может противостоять скомпрометированной ОС и не
проверяет целые фразы. Он не заменяет отдельную холодную резервную копию или
доверенную процедуру аппаратного кошелька. Утерянный мастер-пароль не
восстанавливается; его смена не отзывает старые копии и старые пароли. Разные
сохранённые таблицы одной фразы после раскрытия пароля могут выделить неизменные
настоящие слова. Полная повторная рандомизация строки или таблицы не устраняет
риск пересечения разных версий. Релиз Windows остаётся NO-GO. Прочитайте
[модель угроз](THREAT_MODEL.md#русский) и
[известные ограничения](docs/alpha/known-limitations.md#русский).

Точный кандидат упаковывается только с заметным именем
`Tessaveil-unsigned-synthetic-windows-v1-candidate-<source-sha>` и отдельными
файлами `-runtime.zip`, `-compliance.zip`, `-release-decision.json` и
`-manifest.json`. Манифест связывает имена, размеры и SHA-256 архивов,
`Tessaveil.exe`, SBOM, уведомлений и fail-closed решения. Технический PASS
упаковки не разрешает реальные данные. Храните compliance-архив и внешний
манифест вместе с runtime и проверяйте загруженные байты и GitHub provenance.

Проверки разработки выполняются закреплёнными зависимостями:

```text
python -m pip install -r requirements-dev.txt
python tools/run_tests.py
python -m tools.catalog.cli validate --root . --require-terminal
python -m tools.catalog.cli generate --root . --check
```

`--require-release-ready` ожидаемо остаётся blocked, пока не закрыты обязательные
проверки физических устройств, чистых Windows, съёмных носителей, аудита,
подписи, формата/KDF, типографики, трассировки и evidence точного hosted SHA.
