# Tessaveil

Tessaveil — открытое исследование офлайн-таблицы для резервного хранения мнемонических фраз. Репозиторий теперь содержит рабочую **неподписанную инженерную alpha для Windows только для синтетических данных**, а также спецификации, каталог кошельков и словарей с подтверждающими источниками, модель угроз и технические прототипы. Это **не production-ready, не RC и не stable**; её категорически нельзя использовать для реальных секретов или средств. Совместимость с Android и iOS остаётся будущим требованием, а не текущей возможностью.

Точный предшествующий артефакт ветки на `4c3e9de5b0e7936edc030992584ae6cdd59493ed` прошёл проверки исходников, уведомлений, перелинковки статического Qt и содержимого архивов, а также официального GitHub provenance. Эти доказательства не одобряют последующие коммиты или PR-прогоны и не снимают Windows release/freeze NO-GO. См. [реестр доказательств для точного SHA и оставшиеся блокеры](docs/alpha/release-evidence.md) и [инструкцию alpha только для синтетических данных](docs/alpha/user-guide.md).

Security audit: not yet independently completed

Не используйте этот код или документацию для защиты реальных средств. Не публикуйте настоящие фразы восстановления, приватные ключи, кошельки с активами или файлы хранилища в задачах, запросах на изменения и тестах. Открытый код и автоматические проверки не заменяют независимый аудит безопасности.

В предлагаемой архитектуре Tessaveil кратковременно видит текущее слово и столбец, не может противостоять скомпрометированной ОС и не проверяет целые фразы. Он не заменяет отдельную холодную резервную копию или доверенную процедуру аппаратного кошелька. Идентичные копии одной неизменённой таблицы не добавляют нового сигнала сравнения; разные сохранённые таблицы после расшифровки могут раскрыть неизменные настоящие слова. Полная повторная рандомизация строки или таблицы не устраняет риск пересечения разных версий. Перед оценкой проекта прочитайте [модель угроз и предупреждения о копиях](THREAT_MODEL.md#русский). Завершение исследования не разрешает выпуск продукта: релиз Windows остаётся NO-GO, как и фиксация формата/KDF и неподтверждённые гарантии физических устройств/съёмных носителей.

Правила проекта: [сообщение об уязвимостях](SECURITY.md), [конфиденциальность](PRIVACY.md), [вклад](CONTRIBUTING.md), [подпись кода](CODE_SIGNING_POLICY.md) и [сторонние компоненты](THIRD_PARTY_NOTICES). [English README](README.md).

Оригинальный код проекта распространяется по Apache-2.0. Сторонние словари, материалы источников и другие компоненты сохраняют собственные лицензии и требуют отдельной проверки перед включением или распространением.

Для текущего исследовательского этапа установите закреплённые зависимости командой `python -m pip install -r requirements-dev.txt` и запустите `python tools/run_tests.py`. Проверка завершённости исследования: `python -m tools.catalog.cli validate --root . --require-terminal`; проверка соответствия сгенерированной документации: `python -m tools.catalog.cli generate --root . --check`. Отдельная проверка `python -m tools.catalog.cli validate --root . --require-release-ready` сейчас завершается ошибкой из-за документированных обязательных блокеров; успешное исследование их не снимает.
