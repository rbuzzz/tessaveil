# Privacy

The intended application is offline and transfers no information unless the user explicitly requests it, such as choosing to export or share a file through an operating-system action. It requires no account for ordinary vault use. The application does not submit recovery phrases, vault content, telemetry, or analytics to Tessaveil services.

This is a product requirement, not a claim about an existing release: the repository currently contains research and no functional application. GitHub separately processes information you choose to post in issues, pull requests, or security reports under GitHub's policies. Never post real secret material.

Future network-related features, if any, require a separate design and an explicit update to this policy before implementation.
